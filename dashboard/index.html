Methodology note Segments were formed on standardized RFM (recency, frequency, monetary) and behavioral features using K-Means, with k selected by silhouette score within a business-usable range. Segment agreement with a Gaussian Mixture Model cross-check is shown as the Adjusted Rand Index above — higher values indicate the grouping reflects real structure in the data rather than an artifact of one algorithm's assumptions. CLV is a linear 12-month proxy, not a probabilistic lifetime model.
